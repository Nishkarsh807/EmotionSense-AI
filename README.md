# EmotionSense AI
## Intelligent Real-Time Emotion Analytics Platform

EmotionSense AI is a deep learning based facial emotion recognition system that detects human emotions from facial expressions in real time.

## Features

- Real-time facial emotion detection
- CNN-based emotion classification
- FER2013 dataset training
- 7 emotion categories
- Data visualization and analytics

## Emotions Detected

- Angry
- Disgust
- Fear
- Happy
- Sad
- Surprise
- Neutral

## Tech Stack

- Python
- TensorFlow/Keras
- OpenCV
- CNN
- Streamlit
